Import a Category Format from an Excel spreadsheet.

The spreadsheet must have a specific format:

  • The Category Format data must be the first Sheet of the spreadsheet
  • The first Row of the sheet must be a Header Row.
  • The Header Row must contain a Category column.
  • The Header Row may contain a Gender column and a Aliases column or a Description column.
  • Other header columns are ignored.
  • Capitalization in the Header Row is ignored (Category=category=CATEGORY). Underscores '_' are treated as spaces.
  • Common header names are accepted (for example: Pos=Rank).
